# Capturas de pantalla

Esta carpeta está destinada a las evidencias visuales del proyecto.

Antes de publicar una captura:

1. Oculta contraseñas y tokens.
2. Anonimiza direcciones MAC.
3. Anonimiza direcciones IPv6.
4. Revisa nombres de usuario, rutas personales y direcciones IP.
5. Utiliza nombres descriptivos, por ejemplo:

```text
01_menu_principal.png
02_reporte_generado.png
03_informacion_sistema.png
04_puertos_abiertos.png
05_informacion_red.png
06_archivos_suid.png
```
