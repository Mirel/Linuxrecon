# Metodología de validación

La versión final de LinuxRecon se validó mediante pruebas funcionales sobre un entorno Linux Ubuntu ARM64 virtualizado. Las evidencias comprobaron la generación del informe y la presencia de las secciones previstas, contrastando resultados seleccionados con comandos nativos equivalentes.

Entre los elementos revisados se incluyeron distribución y versión, alias del usuario, rutas de red, puertos y sockets, puntos de montaje, uso de sistemas de archivos, archivos SUID, logs recientes, warnings y el resumen final de seguridad.

La validación respalda la automatización, centralización, repetibilidad y consistencia funcional de la recopilación. No constituye una medición experimental formal de reducción de tiempo ni una demostración estadística de reducción de errores humanos.
